# Library Management System (Mini Version)

## Description
This is a simple Library Management System built using C++ and OOP concepts.  
It allows users to manage books in a library with basic functionalities like adding, issuing, and returning books.

---

Features
- Add new books
- Display all books
- Issue books with due date
- Return books
- Track issued status

---

## Concepts Used
- Object-Oriented Programming (OOP)
- Classes & Objects
- Vectors (Dynamic Arrays)
- Functions
- Conditional Statements
